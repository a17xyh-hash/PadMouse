# 手柄鼠标 · PadMouse

把游戏手柄当成手机鼠标用：**十字键左右翻页、摇杆画圈当滚轮、START 一键切成屏幕指针**。
给"鼠标滚轮坏了""躺着不想伸手划屏幕""手游/阅读器里想用手柄翻页"这类场景用。

- 纯本地运行，**不联网、不申请网络权限、不上传任何数据**
- 免 root 可用（无障碍模式）；有 root 更完整（Root 模式，能读摇杆）
- 体积 60 KB，无第三方依赖，无 Gradle 也能编译

## 先自测一下手势通不通

App 的「测试 / 诊断」里有一条**横向测试条**：

1. 点「测试左滑」/「测试右滑」，测试条会自己滚到屏幕中间，然后收到一次手势。
2. 测试条**跟着动了** = 手势正常发出；如果目标 App 不动，说明那个 App 不吃横向滑动
   （比如浏览器里的普通网页，横滑本来就没东西可滑）。
3. 测试条**不动** = 手势没发出去，看下面那行「注入」是什么：
   `没有可用的注入通道` → 无障碍没开；`✖ 手势被系统取消` → 被目标界面拦了。

同一张卡片里还能调「翻页距离」（默认 30% 屏宽）和「滑动时长」（默认 300ms）——
有些阅读器只认慢一点的拖动，把时长拉到 600~800ms 通常就吃了。

## 两种模式

| | 无障碍模式（免 root） | Root 模式 |
|---|---|---|
| 按键（十字键 / L1 / R1 / A / B …） | 无障碍按键过滤 | 直接读 `/dev/input/eventN` |
| **摇杆** | 需要 **Android 14+** | **任何版本都能读** |
| 抢不抢焦点 | 不抢 | 不抢（evdev 是旁路读取） |
| 需要什么 | 开启无障碍服务 | su 授权（注入仍优先用无障碍手势） |
| 适用 | 大多数人 | 老系统想用摇杆 / 游戏独占输入 |

> Root 模式也建议把无障碍服务开着：手势注入走系统 API 更准更快；万一派发失败，会自动退回
> `su -c input swipe`，保证还能滚。

## 默认映射

| 手柄按键 | 动作 |
|---|---|
| 十字键 ← | **手指往左滑**（翻页） |
| 十字键 → | **手指往右滑**（翻页） |
| 十字键 ↑ / ↓ | 上下滚动一屏的 25% |
| L1 / R1 | 大步滚动（约 2 倍步长） |
| L2 / R2 / L3 / R3 | 大步滚动 |
| 左摇杆 | **画圈当滚轮：顺时针往下、逆时针往上** |
| 右摇杆 | 移动指针（屏幕上那个小圆点） |
| A | 点击（光标模式） |
| X | 长按（光标模式） |
| B | 返回（光标模式） |
| START | 开关光标模式 |
| SELECT | 暂停 / 恢复接管（暂停时摇杆会还给游戏） |

「操作方式」里可以改这几项：

- **十字键**：`左右翻页`（默认）/ `上下滚动`
- **翻页方向**：`按左就往左滑`（默认，方向跟按键一致）/ `按左=上一页`（阅读器里翻反了用这个）
- **左摇杆**：`画圈当滚轮`（默认）/ `推杆滚屏`（推得越深滚得越快）
- **滚动基准**：`指针位置`（默认）/ `屏幕中心`

## 滚动基准 = 指针位置

默认情况下屏幕上会有一个**小圆点当鼠标指针**（右摇杆移动它），
所有滚动、翻页、点击都在**指针所在的位置**发生，而不是固定在屏幕正中：

- 想让右边的列表滚，就把圆点移过去再滚；
- 分屏/多面板界面里，滚哪一块由圆点决定；
- 圆点贴到屏幕边缘时会自动收一点，保证手势还在屏幕内。

切到「屏幕中心」就回到旧行为（不显示圆点，以屏幕正中为基准）。

画圈是"拨轮"的手感：每转 60° 滚一小步（约 1/10 屏），转一圈约滚 0.6 屏；
转得越快滚得越快，「摇杆速度」可以改每格的角度（越大越灵敏）。

所有力度都能在 App 里调：滚动步长、滑动时长、摇杆死区、摇杆速度、光标速度、反向滚动。

## 安装

1. 到 Releases 下载 `PadMouse-0.2.apk` 安装（Android 8.0+）。
2. 打开 App → **打开无障碍设置** → 找到「手柄鼠标」→ 打开。
3. 蓝牙 / USB 连上手柄，随便按一下键，App 的「状态」里应该能看到手柄名字。
4. 回到浏览器 / 阅读 App，用十字键或左摇杆滚屏。

Root 模式：App 里切到「Root · 直读手柄」，首次会弹 su 授权，允许即可。
SukiSU Ultra / KernelSU / APatch / Magisk 都支持；如果没弹窗或读不到，点「Root 诊断」，
它会把 `su 位置 / su -c id / 手柄节点` 全部列出来，一眼看出卡在哪。

<details>
<summary>Root 模式读不到？按这个顺序排查</summary>

1. **先确认 root 本身**：终端里 `su -c id` 能输出 `uid=0(root)` 才算正常。
2. **SukiSU / KernelSU**：打开管理器 → 超级用户 → 允许「手柄鼠标」；
   之前点过拒绝的，先把那条记录删掉，再回 App 点「Root 诊断」重新触发。
3. **授权弹窗没看到**：部分机型要允许管理器的通知；也可以在管理器里先手动把 App 加进白名单。
4. **等不够久**：首次授权要等你点「允许」，App 会等 45 秒 × 3 次，期间屏幕上有提示。
5. **还是不行**：App 会自动切回无障碍模式（不会让你手柄直接失灵），
   把「Root 诊断」复制出来的内容发我即可。
</details>


## 权限说明（就这些）

- **无障碍服务**：只用来 (a) 读手柄按键 (b) 派发滑动手势。`canRetrieveWindowContent=false`，不读屏幕内容。
- **Root（可选）**：读 `/dev/input/event*` 和必要时执行 `input swipe/tap`。不需要的话完全不用给。
- 没有 `INTERNET` 权限，装完可以断网用。

## 已知限制

- 系统锁屏、`FLAG_SECURE` 界面（部分银行/流媒体）里手势注入无效，这是 Android 的限制。
- 少数游戏会用 `EVIOCGRAB` 独占手柄节点，此时 Root 模式也可能读不到；无障碍模式的按键过滤一般还能用。
- 无障碍模式下，**手柄会被本 App 独占**（系统机制：服务订阅了摇杆来源，就不再下发给别的应用）。
  想正常打游戏时按 SELECT 暂停，或关掉服务。
- Android 14 以下、又没有 root 时，摇杆读不到，只能用按键滚（这是系统 API 的限制）。
- 光标模式是"点一下走一步"的指针，不是系统级鼠标指针，不能拖拽选词。

## 自己编译

不用 Gradle，直接用 SDK build-tools：

```bash
# 需要 JDK 17、Android SDK（build-tools 35、platform android-35）、node（mkzip.js 打包 dex）
./build.sh                                   # 产出 ./PadMouse-0.1.apk
VER_CODE=2 VER_NAME=0.2 ./build.sh /tmp/p.apk
```

签名默认用调试 keystore，可以通过环境变量指定自己的：

```bash
KS=/path/to/your.keystore ./build.sh
```

## 代码结构

```
app/src/main/java/com/padmouse/
├── MainActivity.java     设置界面（纯代码布局，无 XML 依赖）
├── PadMouseService.java  无障碍服务：按键映射、摇杆、手势派发、浮层
├── RootPad.java          Root 模式：扫 /proc/bus/input/devices + 解析 evdev 原始事件
├── RootShell.java        常驻 su shell，带命令排队与完成标记
├── RootProbe.java        Root 诊断（su 位置 / su -c id / 输入节点）
├── CursorOverlay.java    光标模式的小圆点浮层
├── Prefs.java            全部参数与默认值
├── Dbg.java              给界面看的诊断信息
└── KeyNames.java         按键名 -> 人话
```

实现细节见 [docs/TECH.md](docs/TECH.md)。

  指针（小圆点）一直显示，右摇杆移动；贴边时自动内收，保证手势不出屏。
- **0.6**：修正"十字键被当成左摇杆"——之前把 `AXIS_HAT_X/Y` 并进了 LX/LY，
  按 ←/→ 看起来像在推摇杆，翻页自然没反应。现在 HAT 单独转成方向键（两种模式都改了），
  诊断里也会显示 `HAT ±1,±1`；带"这个手柄本来就发方向键就不再补"的去重。
- **0.5**：翻页手势改成最普通的"屏幕中间按下 → 平移 → 抬起"（多段路径，避免被当成 fling）；
  新增横向测试条 + 「测试左滑/右滑」按钮，能直接看出手势有没有发出去；
  新增「翻页距离」滑杆，滑动时长上限放宽到 1000ms。
- **0.4**：翻页方向改成"按左就往左滑、按右就往右滑"，↑/↓ 恢复上下滚动；
  Root 模式下十字键走 `ABS_HAT0X/Y` 时自动转成方向键；按键动作不再被正在播放的手势吞掉。
- **0.3**：Root 通道重写——多个 su 路径轮试、授权等待、按分数挑手柄节点、
  读不到自动回退无障碍模式，新增「Root 诊断」；修了提示浮条的线程问题。
- **0.2**：十字键改成左右翻页；左摇杆画圈当滚轮（顺时针下 / 逆时针上）。
- **0.1**：首个版本，无障碍 + Root 双模式。
